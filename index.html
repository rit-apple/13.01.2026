Из каких имён и на каких уровнях иерархии состоит доменное имя моего сайта

Опубликовано: 13 января 2026 г.

Доменное имя моего сайта — ваш-логин.github.io — состоит из нескольких уровней, организованных в иерархическую структуру DNS (Domain Name System). Рассмотрим каждый уровень, двигаясь справа налево — от корня к конкретному поддомену.

Уровни доменного имени

Уровень Часть домена Название Описание
0 . Корневой домен (Root) Неявная точка в конце полного доменного имени (FQDN). Обычно не отображается, но существует в DNS.
1 .io Домен верхнего уровня (TLD) Country-code TLD (ccTLD) для Британской территории Индийского океана. Популярен в IT-среде.
2 .github.io Домен второго уровня (SLD) Зарегистрирован компанией GitHub для предоставления бесплатных сайтов пользователям.
3 ваш-логин.github.io Поддомен третьего уровня Ваш уникальный поддомен, автоматически создаваемый GitHub на основе имени аккаунта.

Пример полного пути в DNS

Полное доменное имя (FQDN): ваш-логин.github.io. (обратите внимание на точку в конце — это корень DNS).

💡 Чем правее часть домена — тем она «выше» в иерархии. Например, зона .io управляется одним регистратором, а внутри неё GitHub управляет зоной github.io, а вы — своим поддоменом ваш-логин.

Таким образом, система DNS построена как перевёрнутое дерево: от глобального корня — к вашему персональному веб-пространству.
